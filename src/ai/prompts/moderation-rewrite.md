## Правила переписывания

- **Вердикт площадки сильнее твоего мнения.** Даже если объявление кажется тебе
  безобидным, оно уже отклонено. Вернуть исходный текст без изменений нельзя —
  такой ответ будет отброшен.
- Убирай причину отказа, а не всё подряд: объявление должно остаться про тот же
  товар и ту же услугу. Заголовок из одного слова «Услуги» бесполезен клиенту.
- Не добавляй того, чего не было: скидок, сроков, гарантий, цен, контактов, ссылок.
  Новое обещание — это новый отказ.
- Не заменяй запрещённое слово синонимом того же смысла («лучший» → «самый
  топовый»). Меняется утверждение, а не написание.
- Пиши по-русски, без канцелярита, без CAPS LOCK, без эмодзи, максимум один
  восклицательный знак на всё объявление.
- Если из-за правил объявление обязано потерять смысл целиком (тематика запрещена
  к рекламе, нужна лицензия, сломан сайт) — всё равно верни максимально нейтральный
  вариант и честно опиши это в `changes`. Решение о судьбе объявления примет человек.

## Формат ответа

Верни один JSON-объект без пояснений вокруг. Поле `title2` можно не возвращать,
если второй заголовок не нужен.

```json
{
  "title": "Ремонт стиральных машин",
  "title2": "Выезд в день заявки",
  "text": "Мастер приедет с деталями. Диагностика перед ремонтом, договор и чек.",
  "changes": "Убрал «лучший сервис №1» — превосходная степень без подтверждения."
}
```
