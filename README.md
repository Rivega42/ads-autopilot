# ads-autopilot

Полностью автономный AI-агент для управления рекламными кампаниями.

**Каналы:** Яндекс Директ, VK Реклама, TikTok Marketing, LinkedIn Marketing, Meta Ads, Google Ads, Telegram Ads.

**Роль человека:** три точки контакта — онбординг (15 мин), апрув крупных изменений (2-3 мин раз в 2-3 дня), стратегический разбор (30 мин в месяц). Всё остальное делает AI.

## Что внутри

- **AI-Онбординг** — диалоговое интервью, портрет клиента и УТП
- **AI-Стратег** — план кампании с анализом конкурентов
- **AI-Креативы** — тексты (Claude/GPT) + картинки (Kandinsky/DALL-E) + видео (Runway/Sora)
- **AI-Модератор** — авто-переработка отклонённых объявлений
- **AI-Оптимизатор** — ML-модель + LLM-агент вместо статичных правил
- **AI-Аналитик** — недельные разборы с инсайтами
- **AI-Конкурентная разведка** — мониторинг топ-10 конкурентов
- **AI-Wordstat** — генерация семантики через LLM + эмбеддинги
- **AI-Follow-up** — квалификация лидов в мессенджерах
