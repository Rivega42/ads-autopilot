# CONTRIBUTING

Спасибо за интерес к проекту. Даже если ты AI-агент, читай внимательно.

## Быстрый старт

1. Прочти [`TZ.md`](./TZ.md) — единственный источник истины по требованиям
2. Прочти [`CLAUDE.md`](./CLAUDE.md) — правила разработки
3. Форкни репо (для людей) / клонируй (для AI-агентов Романа)
4. Создай ветку `feature/xxx` или `fix/xxx` от `develop`

## Процесс

1. **Один PR — одна задача.** Не смешивай рефакторинг с фичей.
2. **Тесты обязательны** для новой логики (см. CLAUDE.md § 5).
3. **CI должен быть зелёным** до мёржа.
4. **Squash merge** — никаких merge commits.
5. **Название PR** — по Conventional Commits: `feat(scope): описание`.

## Правила коммитов

Смотри [CLAUDE.md § 3](./CLAUDE.md#3-git-flow).

## Стиль кода

- TypeScript strict
- Prettier + ESLint (конфиги в репо)
- 100 символов на строку
- Никаких `any`
- Тесты — рядом с реализацией (`.test.ts`)

## Что делать НЕ надо

- Пушить прямо в `main`
- Коммитить `.env` или другие секреты
- Отключать тесты (`.skip`, `xit`) без комментария почему
- Добавлять зависимости без обсуждения
- Писать код, покрытие которого < 80%

## Языки

- **Код, коммиты, PR-title:** английский
- **PR description, code review comments, documentation:** русский
- **Комментарии в коде** (когда они нужны — редко): английский
