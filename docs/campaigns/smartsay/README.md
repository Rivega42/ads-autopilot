Полностью проработанный рекламный аккаунт языковой школы SmartSay: 11 кампаний,
26 групп, 213 ключевых фраз, 114 общих минус-слов, объявления под каждый сегмент.

## Файлы для загрузки

```
export/
├── all-campaigns.tsv          все кампании одной таблицей
├── commander/*.tsv            по одному файлу на кампанию
├── keywords/*.txt             ключевые фразы по группам
├── negatives/global.txt       общий список минус-слов на аккаунт
├── negatives/campaign-*.txt   минус-слова по кампаниям
├── sitelinks.tsv              8 быстрых ссылок
├── callouts.txt               10 уточнений
└── utm-template.txt           UTM-разметка для поля «Параметры URL»
```

Источник истины — `src/campaigns/smartsay/blueprint.ts`. Правки вносим туда,
затем перегенерируем:

```bash
pnpm campaign:smartsay          # файлы для ручной загрузки
pnpm campaign:deploy            # холостой прогон заливки через API
pnpm campaign:deploy --apply --counter <id>   # боевая заливка, кампании остановлены
pnpm yd:check                   # есть ли доступ к API
```

Все объявления автоматически проверяются на лимиты Директа (длина заголовков,
текстов, быстрых ссылок, уточнений, количество слов во фразе) и на дубли фраз
между группами одной кампании:

```bash
pnpm vitest run src/campaigns
```

## Три вещи, которые нужно сделать до первого клика

1. **Поставить счётчик Яндекс.Метрики.** Сейчас его на сайте нет — проверено по
   бандлу `smartsay.ru/assets/index-*.js`. Без счётчика и целей не работают ни
   автостратегии, ни ретаргетинг, ни оценка CPL. Детали — в
   [02-metrika.md](./02-metrika.md).
2. **Починить расхождение адресов.** В FAQ указан «Санкт-Петербургский проспект,
   д. 60», в контактах и на Яндекс.Картах — «Петергоф, ул. Чичеринская, д. 2».
3. **Уточнить часы работы** — на сайте их нет, а визитка в Директе их требует.
