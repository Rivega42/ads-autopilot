# Яндекс.Метрика: блокер запуска

## Проблема

На smartsay.ru **нет счётчика Яндекс.Метрики**. Проверено по собранному
бандлу сайта: в `https://smartsay.ru/assets/index-D4gZpGIR.js` нет ни
`mc.yandex.ru`, ни вызовов `ym(`, ни какого-либо другого счётчика.

Что из этого следует:

- Директ не увидит ни одной конверсии → автостратегии «Максимум конверсий»
  и оплата за конверсии физически не смогут работать.
- Нельзя собрать аудитории → кампания ретаргетинга не запустится (нужно
  минимум 100 человек в сегменте).
- Нельзя посчитать CPL и понять, какие ключи окупаются, — оптимизация
  выродится в «смотрим на CTR», что для школы бессмысленно.

Запускать трафик без счётчика можно (кампании на стратегии «Максимум кликов»
поедут), но это будет слив бюджета вслепую. **Счётчик ставим до первого клика.**

## Что сделать

### 1. Создать счётчик

metrika.yandex.ru → «Добавить счётчик»:

- Имя: `smartsay.ru`
- Домен: `smartsay.ru`, дополнительно `www.smartsay.ru`
- Включить: **Вебвизор**, **Карта скроллинга**, **Аналитика форм**
- Включить: **Электронная коммерция** (пригодится, когда появится оплата
  абонементов онлайн)
- Часовой пояс: Europe/Moscow

### 2. Установить код

Сайт — SPA на React (Vite). Это важно: при переходах между разделами страница
не перезагружается, и счётчик по умолчанию засчитает только первый просмотр.

Базовый код ставим в `index.html` в `<head>`, а на смену маршрута
дополнительно отправляем хит. В связке с React Router это выглядит так:

```ts
// src/analytics/metrika.ts
declare global {
  interface Window {
    ym?: (id: number, action: string, ...args: unknown[]) => void;
  }
}

const COUNTER_ID = 0; // подставить реальный ID

export function trackPageView(url: string): void {
  window.ym?.(COUNTER_ID, 'hit', url);
}

export function reachGoal(goal: string, params?: Record<string, unknown>): void {
  window.ym?.(COUNTER_ID, 'reachGoal', goal, params);
}
```

и вызываем `trackPageView(location.pathname + location.search)` в
`useEffect` на изменение `location`.

### 3. Настроить цели

Порядок важен: сначала микроконверсии (их много, они разгонят обучение
стратегий), потом макро.

| Цель                           | Идентификатор         | Тип                             | Ценность, ₽ | Зачем                                   |
| ------------------------------ | --------------------- | ------------------------------- | ----------: | --------------------------------------- |
| Отправка формы записи          | `form_lead`           | JavaScript-событие              |        1500 | **Главная цель.** На неё оптимизируем   |
| Отправка формы на `/preschool` | `form_lead_preschool` | JavaScript-событие              |        1200 | Отдельный продукт, отдельная экономика  |
| Отправка формы на `/camp`      | `form_lead_camp`      | JavaScript-событие              |        5000 | Чек выше на порядок                     |
| Клик по телефону               | `click_phone`         | JavaScript-событие              |        1200 | Для локальной школы звонков будет много |
| Клик по Telegram / мессенджеру | `click_messenger`     | JavaScript-событие              |         800 |                                         |
| Клик по email                  | `click_email`         | JavaScript-событие              |         400 |                                         |
| Пройден тест `/smarttest`      | `test_completed`      | JavaScript-событие              |         300 | Микроконверсия для разгона стратегий    |
| Просмотр цен                   | `viewed_pricing`      | JavaScript-событие              |         100 | Микроконверсия                          |
| Вовлечённый визит              | `engaged_visit`       | Составная: 3 просмотра + 90 сек |          50 | Микроконверсия                          |
| Клик «Открыть в Яндекс.Картах» | `click_maps`          | JavaScript-событие              |         600 | Сильный сигнал локального интента       |

Отправка цели из кода:

```ts
reachGoal('form_lead', { language: 'english', format: 'group' });
```

Параметры визита (`language`, `format`, `age_group`) потом позволят в отчётах
Метрики увидеть, какой язык и формат реально окупается.

### 4. Связать Метрику с Директом

1. В Директе: «Настройки кампании» → «Счётчики Метрики» → добавить ID счётчика
   во **все** кампании.
2. В Метрике: «Настройки» → «Доступ» → выдать доступ аккаунту Директа.
3. Включить **разметку ссылок для Метрики** (`yclid`) — в кампаниях это галочка
   «Размечать ссылки для Метрики».
4. Включить **автоматическую отправку офлайн-конверсий**, когда появится CRM:
   ученик, дошедший до оплаты, — это и есть настоящая макроконверсия.

### 5. Сегменты для ретаргетинга

Создаём в Метрике → «Сегменты», затем в Директе → «Библиотека» →
«Ретаргетинг и аудитории».

| Сегмент                        | Условие                                                         | Использование                                             |
| ------------------------------ | --------------------------------------------------------------- | --------------------------------------------------------- |
| `Был на /courses без заявки`   | посещение `/courses`, не достигнута `form_lead`, 30 дней        | основной ретаргетинг                                      |
| `Был на /preschool без заявки` | посещение `/preschool`, не достигнута `form_lead`, 30 дней      | отдельные объявления про детский центр                    |
| `Смотрел цены`                 | достигнута `viewed_pricing`, не достигнута `form_lead`, 14 дней | самый горячий сегмент, повышенная ставка                  |
| `Прошёл тест, не записался`    | `test_completed` без `form_lead`, 30 дней                       | оффер «разберём результаты теста на пробном уроке»        |
| `Уже оставил заявку`           | достигнута `form_lead`, 90 дней                                 | **исключаем** из всех кампаний, чтобы не платить за своих |
| `Look-alike от заявок`         | Яндекс Аудитории, похожие на сегмент `form_lead`                | масштабирование РСЯ                                       |

Сегмент «Уже оставил заявку» обязательно добавить как **корректировку −100%**
во все кампании, кроме брендовой.

## Порог, после которого меняем стратегию

Автостратегия «Максимум конверсий» начинает работать осмысленно от
**10 конверсий в неделю на кампанию**, оплата за конверсии — от того же
порога и после набора статистики. До этого держим «Максимум кликов
с недельным бюджетом» и оптимизируем руками по отчётам.

Если целевых конверсий мало — временно оптимизируемся на составную цель
«любая заявка ИЛИ клик по телефону ИЛИ пройденный тест»: она набирает объём
быстрее и разгоняет обучение.
