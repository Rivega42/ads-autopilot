## Этап 2. Создание кампаний

Для каждой кампании из `export/commander/` — тип **Единая перфоманс-кампания**,
режим эксперта (Директ Про).

- [ ] Название взято из колонки «Название кампании» — не переименовывать,
      оно используется в UTM через `{campaign_name}`
- [ ] Места показа выставлены по типу: `search` → только Поиск,
      `network` → только РСЯ, `retargeting` → РСЯ + Карты
- [ ] Стратегия: «Максимум кликов с ограничением недельного бюджета»
      (для брендовой и корпоративной — «Максимум кликов с ручными ставками»)
- [ ] Недельный бюджет проставлен по таблице из [01-strategy.md](./01-strategy.md#5-бюджет-и-приоритеты-запуска)
- [ ] Регионы показа взяты из колонки «Регионы показа»
- [ ] В поле «Параметры URL» вставлено содержимое `export/utm-template.txt`
- [ ] Подключён счётчик Метрики и включена разметка `yclid`
- [ ] Ключевые цели: `form_lead` (ценность 1500 ₽), `click_phone` (1200 ₽),
      `click_messenger` (800 ₽)
- [ ] Загружены минус-фразы кампании из `export/negatives/campaign-*.txt`
- [ ] Прикреплены быстрые ссылки, уточнения и визитка из библиотеки

### Как загружать TSV

Файлы `export/commander/*.tsv` — обычные таблицы с табуляцией. Два рабочих пути:

**Через Директ Коммандер (быстрее для больших объёмов):**
открыть файл в Excel или Google Таблицах → выделить нужные колонки →
скопировать → в Коммандере встать на первую строку таблицы групп или
объявлений → вставить.

**Через XLS-загрузку Директа:** в интерфейсе Директа выгрузить пустой
шаблон кампании («Кампании» → «Управление кампаниями через Excel» →
«Выгрузить»), затем перенести данные из TSV в колонки шаблона с
совпадающими названиями и загрузить обратно. Порядок колонок в шаблоне
Директа со временем меняется, поэтому сверяйся с выгруженным шаблоном,
а не с порядком в TSV.
