# Креативы для РСЯ

15 готовых изображений: 5 сюжетов × 3 соотношения. Лежат в [`out/`](./out/).

```bash
python3 docs/campaigns/smartsay/creatives/strip-bg.py   # снять подложку с исходников
node docs/campaigns/smartsay/creatives/render.mjs       # пересобрать креативы
```

Правки — в `creatives.html`. Картинки только пересобираются, руками их не трогаем.

## Что к какой кампании

| Файл          | Кампания                                                | Оффер на картинке                              |
| ------------- | ------------------------------------------------------- | ---------------------------------------------- |
| `adults-*`    | SS \| Поиск \| Взрослые \| Петергоф · SS \| РСЯ \| Очно | Английский для взрослых, первый урок бесплатно |
| `kids-*`      | SS \| Поиск \| Дети и школьники \| Петергоф             | Английский детям 7–17, пробный урок 0 ₽        |
| `preschool-*` | SS \| Поиск \| Дошкольники 3–6 \| Петергоф              | Детский клуб 3–6 лет, от 4 500 ₽/мес           |
| `online-*`    | SS \| Поиск \| Онлайн-школа \| РФ · SS \| РСЯ \| Онлайн | Языки онлайн, первый урок бесплатно            |
| `brand-*`     | SS \| Поиск \| Бренд · SS \| Ретаргетинг                | 4 языка в одной школе                          |

Размеры под требования Директа: `1x1` — 1200×1200, `16x9` — 1920×1080,
`3x4` — 1200×1600. Все файлы 116–204 КБ при лимите 10 МБ. В каждую группу
РСЯ грузим все три соотношения — Директ сам подберёт формат под площадку.

## Что было на сайте на 8 августа 2026

Своей фотобазы у школы нет. Всё, что нашлось в бандле:

| Исходник                                                                                   | Что это                                  | Годность для рекламы                        |
| ------------------------------------------------------------------------------------------ | ---------------------------------------- | ------------------------------------------- |
| 4 персонажа в бирюзовом (`consultant`, `girl_thumbs_up`, `man_cutout`, `student_pointing`) | сгенерированные фигуры на белой подложке | использованы — прав третьих лиц не нарушают |
| `image_...608934`                                                                          | сгенерированный малыш в очках с флагами  | использован для дошкольного центра          |
| `image_...590715`, `...599866`, `...619051`                                                | реальные фото учеников на чёрном фоне    | **не использованы** — см. ниже              |
| Логотип 3580×876                                                                           | нормальный, с запасом по разрешению      | использован                                 |

Подложки пришлось снимать самим: вырезки лежат на сплошном белом или чёрном
фоне, а не на альфа-канале, — в объявлении они отрисовались бы белым или
чёрным прямоугольником. Этим занимается `strip-bg.py`: заливка идёт от краёв
кадра внутрь, поэтому белая рубашка внутри силуэта остаётся белой.

## Три проблемы, которые решает не дизайнер

1. **Реальные фото учеников — несовершеннолетние.** На трёх фотографиях дети
   и подростки. Для показа в рекламе нужно письменное согласие родителей на
   использование изображения. Пока согласий нет — эти кадры в объявления не
   идут, поэтому в детских креативах стоят сгенерированные персонажи.
2. **«Преподаватели» на сайте — стоковые портреты с Unsplash.** В бандле пять
   ссылок вида `images.unsplash.com/photo-...?crop=face`. Выдавать их за своих
   педагогов в рекламе нельзя: это и вводит покупателя в заблуждение, и
   нарушает лицензию Unsplash, которая запрещает использовать изображения людей
   так, будто они одобряют услугу. В креативы они не взяты.
3. **`/og-image.jpg`, `/logo.png` и `/favicon.ico` на сервере отсутствуют** —
   вместо файлов отдаётся `index.html` SPA. Ссылки на них стоят в мета-тегах,
   так что превью при репостах и иконка вкладки сейчас сломаны. К Директу
   отношения не имеет, но чинится за десять минут.

## Что снять, чтобы креативы стали сильно лучше

Сгенерированные персонажи закрывают запуск, но в РСЯ реальные фото места и
людей стабильно дают выше CTR: человек узнаёт свой район. Съёмка на полдня
закрывает весь год.

| Кадр                                                                  | Под какую кампанию    | Требования                              |
| --------------------------------------------------------------------- | --------------------- | --------------------------------------- |
| Фасад здания на Чичеринской, 2 с вывеской, светлое время              | Взрослые, Дети, Бренд | горизонталь, узнаваемое окружение       |
| Занятие взрослой группы: 4–6 человек за столом, преподаватель говорит | Взрослые              | без постановочных «идеальных» улыбок    |
| Занятие детской группы 7–12                                           | Дети и школьники      | согласия родителей до съёмки            |
| Игровая дошкольного центра: ковёр, материалы, педагог с детьми        | Дошкольники           | согласия родителей                      |
| Портреты 4–6 реальных преподавателей на однотонном фоне               | Все + сайт            | заменить сток на сайте                  |
| Кабинет для онлайн-занятий: педагог в наушниках у экрана              | Онлайн-школа          | видно интерфейс урока                   |
| Лагерь: смена, активности, природа                                    | Языковой лагерь       | снимать летом, для февральского запуска |

Технически: горизонт 3000 px по длинной стороне, съёмка и по горизонтали, и по
вертикали (нужны 1:1, 16:9 и 3:4), запас по краям под кадрирование, без
пересвеченных окон в кадре.

## Известное ограничение текущего комплекта

У сгенерированного малыша вьющиеся волосы — после снятия чёрной подложки по
контуру причёски остаются мелкие тёмные точки. На размерах показа в РСЯ они не
читаются, но при замене на реальную фотографию проблема уходит сама.
